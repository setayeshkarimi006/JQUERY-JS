# ✨ Vanilla JS vs jQuery — A Modern Web Experience

A modern, responsive web project built with **HTML, Tailwind CSS, Vanilla JavaScript, and jQuery**.

This project demonstrates how common interactive web features can be implemented using two different approaches: pure JavaScript and jQuery — all wrapped in a clean, modern UI.

## 💻 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd equivalent-js-jquery
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

---

## 🏗️ Build for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 🎯 Project Purpose

The main goal of this project is to explore the differences between Vanilla JavaScript and jQuery by implementing similar interactive components with both technologies.

It is also an opportunity to practice responsive web design, modern UI development, DOM manipulation, and front-end project organization.
